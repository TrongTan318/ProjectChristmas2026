Nhạc nền website: thả file .mp3 (hoặc .m4a/.aac/.ogg/.opus/.webm) vào thư mục này.

- Tên bài lấy từ tên file, ví dụ "Dem-Thanh-Vo-Cung.mp3" -> "Dem Thanh Vo Cung".
- Nên nén ~128kbps (mỗi bài ~3-4MB) để tiết kiệm băng thông.
- Sau khi thêm/bớt file: docker compose restart app
- Chỉ dùng nhạc được phép phát công khai.
